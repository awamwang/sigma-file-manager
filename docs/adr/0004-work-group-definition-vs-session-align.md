# Work Group definition writes immediately; Active session aligns on prompt

All editors write the same Work Group definition immediately. The product goal is keeping the Active session in sync with that definition—no per-group historical baseline. While a group is Active and the user is on Navigator, membership or Group Navigator Defaults writes accumulate an Active-only pending delta and raise a coalesced Session Align Prompt: apply defaults and open tabs for members added in that delta that still lack an exact-path tab; never auto-close removed members. Declining only defers alignment. Off-Navigator Active edits stay silent until return to Navigator. Activating another Work Group restores its Open State, clears any Active pending delta, then opens member folders the target has but the previous Active group does not. Missing member paths stay listed on the management page. Leaving the Active group prefers the Switch Save Prompt over a pending align prompt, and may offer to open still-unopened new member tabs before saving Open State, with dirty/replace tab counts emphasized.
