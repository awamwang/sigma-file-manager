# Work Group definition writes immediately; Active session aligns on prompt

All editors write the same Work Group definition immediately. The product goal is keeping the Active session in sync with that definition—no per-group historical baseline. Active-only pending deltas drive sync: edits made while already on Navigator raise a Session Align Prompt; edits made away from Navigator auto-apply when Navigator is entered again (open newly added member tabs that still lack an exact-path tab; never auto-close removed members). Declining a prompt only defers alignment. Opening the already-Active group from the management page also resumes pending opens after navigating to Navigator. Activating another Work Group restores its Open State, clears any Active pending delta, then opens member folders the target has but the previous Active group does not. Missing member paths stay listed on the management page. Leaving the Active group prefers the Switch Save Prompt over a pending align prompt, and may offer to open still-unopened new member tabs before saving Open State, with dirty/replace tab counts emphasized.
