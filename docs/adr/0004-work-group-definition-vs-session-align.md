# Work Group definition writes immediately; Active session aligns on prompt

All editors (management page, Navigator context menu, path maintenance) write the same Work Group definition at once. Reconciling the live Active Navigator session is separate: while that group is Active and the user is on Navigator, membership or Group Navigator Defaults changes raise a coalesced Session Align Prompt — apply defaults and open tabs only for newly added members still lacking an exact-path tab; never auto-close tabs for removed members. Declining only defers alignment; the definition stays. Off-Navigator edits to the Active group stay silent until return to Navigator. Missing member paths are kept and flagged on the management page, not auto-removed there; Navigator sync does not prompt for those removals. Leaving the Active group prefers the Switch Save Prompt over a pending align prompt, and that dialog may offer to open still-unopened new member tabs before saving Open State, while showing dirty and replace tab counts with closed counts emphasized.
